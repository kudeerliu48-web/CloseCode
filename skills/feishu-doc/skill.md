# 飞书文档交付

先完成内容本身并保留本地版本。只有用户要求创建/发布飞书文档时才调用 feishu_doc_create；普通写作或会议纪要不自动上传。

- 检查当前工具列表是否提供 feishu_doc_create。缺少工具、配置或权限时报告原因，交付本地文档/Markdown 作为替代，不索取或打印密钥。
- 标题和 Markdown 使用审核后的内容。表格、标题和列表保持层级清楚；本地图片使用确实存在的工作目录路径，并注意敏感信息不应自动对外共享。
- 以工具实际返回的文档链接和状态为准；失败不谎报成功。网络状态不明时先确认是否已创建，避免盲目重试生成重复文档。
- 交付真实链接、本地备份路径以及上传失败的资源或格式限制；不扩大分享范围，也不擅自修改用户已有云端文档。
