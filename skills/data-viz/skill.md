# 数据可视化

先读取用户数据或前序专家的研究笔记，检查字段、单位、缺失值、统计区间、来源。没有可靠数据时说明缺口；演示数据必须显著标注，不能冒充实测。

- 趋势用折线，类别比较用柱形，关系用散点。轴标题、单位、图例与统计期要明确；避免截断轴造成误导。
- 优先使用 gen_diagram 的 echarts 类型，source 传 option；流程/架构使用其 mermaid 或 dot 类型。按实际返回结果交付 SVG/PNG，不假定环境一定能生成 PNG。
- 写出底层数据或计算脚本以便复用，检查聚合、百分比和总计。数据量大时先用 run_node 处理，不手工抄数。
- 使用可用的图像查看工具检查文字是否被裁切、中文是否可读、颜色是否能区分。无法预览时声明仅做结构校验。
- 交接图表路径、含义、数据来源、统计口径和限制；需插入 Word/PPT 时明确实际可用的图片格式。
