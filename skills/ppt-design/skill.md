# 演示文稿制作

先确认受众、用途、页数范围和用户提供的素材。复用前序研究与图表，先列出每页核心结论，再排版。

- 使用 run_node 和已安装的 pptxgenjs 生成真实 .pptx 文件，遵循项目实际版本/API；不把 Markdown 改后缀交付。
- 统一页面比例、字体、颜色和间距；每页以一个中心结论为主。标题和正文留足空间，不用大量缩小字号解决溢出。
- 数据页附来源与时间口径。只使用真实存在且获准使用的图片，保持比例；没有图像时用清晰的可编辑文本/形状而不是伪造图片。
- 写入前检查图片路径与异步任务，写入后用文件列表确认产物，并用 jszip 检查 PPTX 包内幻灯片数量、文本和资源引用。
- 有可用渲染器时逐页渲染检查遮挡、裁切与可读性；没有时明确尚未完成视觉验收，不声称逐页看过。
- 交付文件路径、页数、素材来源和尚存限制；除非要求，不另外发布到外部平台。
