# 周报整理

以用户记录、附件和已有项目进度为依据，明确本周起止日期。不凭空补工作量、完成率或业务指标。

- 将零散记录归并为项目/目标，去重，并区分已完成、进行中、阻塞。以可验证结果代替“积极推进”等空话。
- 每个重要事项说明结果、影响和证据；风险写清依赖与待决策项。缺失负责人或时间时标记待确认，不替用户承诺。
- 下周计划对应未完成目标，列出交付物与优先级；没有明确授权不自动分配同事任务。
- 按用户模板输出；无模板可用“本周成果 / 进行中事项 / 风险与支持 / 下周计划”。短周报直接正文，要求文件时保存到当前工作目录。
- 如需 Word 文件，使用可用的 word-processing 技能；不要仅改扩展名。核对日期、指标和状态前后一致。
