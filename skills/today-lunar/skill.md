# 今日农历 · 节日 · 节气

查询指定公历日期（默认今天）的农历日期、当前/邻近节气、传统节日、公历纪念日与法定放假安排。对标 `today-weather`：必须联网取真数据，禁止用过时公式或记忆里的年份表硬编。

## 适用场景

- 「今天农历几号 / 今天黄历」
- 「今日节气是什么 / 白露过了没」
- 「今天有什么节日 / 离中秋还有几天」
- 「某年某月某日农历是几号、是不是节假日」
- 写日报、海报、日历页前需要农历与节气文案

## 执行流程

### 1. 确定查询日期

- **没说日期**：用系统当前日期（提示词里的「现在是 YYYY 年 M 月 D 日」）。不要用训练数据里的「今天」。
- **说了日期**：解析为 `YYYY-MM-DD`。只有月日则默认当年。
- **农历反查**（「农历八月十五是哪天」）：走下方农历 API 的 `type=lunar`，得到公历后再按公历流程查节气/放假。
- 同时算出星期（可 `run_node` 用 `new Date(Date.UTC(y, m-1, d))` 再转北京时间，或直接信权威页）。

后续步骤里把日期记作 `Y / M / D`。

### 2. 农历（必做，先走 API）

**主源（已验证，2026-09-08 实测通）**：蛙蛙工具农历 API。`fetch_url` 不一定带自定义 UA，**必须用 `run_shell` + curl**：

```bash
curl -s -A "iamwawa-open-api" "https://www.iamwawa.cn/nongli/api/?type=solar&year=Y&month=M&day=D"
```

成功形态：

```json
{
  "status": 1,
  "info": "success",
  "data": {
    "solar": "2026年9月8日",
    "lunar": "2026年7月27日",
    "ganzhi": "丙午年",
    "lunar_date": "七月廿七",
    "zodiac": "马",
    "constellation": "处女座"
  }
}
```

约束：每小时约 60 次；公历 -104～2300。`status !== 1` 立刻换备源，不要重试刷接口。

**备源（至少再对一处，农历必须交叉）**：

1. `fetch_url("https://wannianli.tianqi.com/Y/M/D/")`  
   页面里有「农历：Y年M月D日 / 七月廿七 / 干支」。注意该站日历格和详情卡的干支可能不一致，**以详情卡「干支：丙午年 丁酉月 乙酉日」为准**，日历格子只作农历日交叉。
2. `web_search({ query: "Y年M月D日 农历", count: 5 })` 后抓百度日历摘要、权威转载。
3. 百度搜索页 `https://www.baidu.com/s?wd=Y年M月D日 农历` 的日历组件（含农历日、当日标注）。

农历月日、干支年、生肖三处对不上就再抓一源；对不上的字段标「来源不一致，以 A 为准」。**禁止用自写农历算法交差**（闰月、大小月极易算错）。

### 3. 二十四节气（必做，禁止本地近似公式）

节气时刻按太阳黄经，每年会前后挪一天。**禁止**使用「1900 年小寒 + 31556925974.7 ms」这类老黄历近似——2026 年白露会被错算到 9 月 8 日，权威源是 **9 月 7 日 22:41**。

**主源**：`fetch_url("https://www.iamwawa.cn/jieqi.html")`  
页面是**当前公历年**的 24 节气表（名称、公历、农历、时刻）。查哪一年就用哪一年的表；若页面仍是「今年」而用户问的是别的年份：

1. `web_search({ query: "Y年 二十四节气 时间表", count: 5 })`
2. `fetch_url("https://wannianli.tianqi.com/Y/M/")` 月历格里会标出当月节气（如 9/7 白露、9/23 秋分）
3. 香港天文台年历（`www.hko.gov.hk` Almanac）作权威交叉（可能超时，失败就换）

从全年 24 条里算出：

- **当日是否节气**：公历年月日完全相等 → 就是该节气（可附时刻）
- **当前节气**：最后一个「日期 ≤ 查询日」的节气
- **下一节气**：第一个「日期 > 查询日」的节气，并算间隔天数
- 查询日在去年冬至之后、今年小寒之前时，当前节气是去年冬至（要补抓 Y-1 年冬至）

### 4. 节日与放假

分四层，不要混成一句「今天没节日」。

#### 4.1 传统农历节日（用第 2 步的农历月日匹配）

月日用中文（正月/冬月/腊月，初一～三十）。闰月：仅当用户问的就是闰月，或来源明确标了闰月时，才把「闰X月Y日」按该节日算；默认不把闰月当成正节。

| 农历 | 节日 |
| --- | --- |
| 正月初一 | 春节 |
| 正月十五 | 元宵节 |
| 二月初二 | 龙抬头 |
| 三月初三 | 上巳节 |
| 四月初八 | 浴佛节 |
| 五月初五 | 端午节 |
| 七月初七 | 七夕 |
| 七月十五 | 中元节 |
| 八月十五 | 中秋节 |
| 九月初九 | 重阳节 |
| 十月初一 | 寒衣节 |
| 十月十五 | 下元节 |
| 腊月初八 | 腊八节 |
| 腊月廿三 或 廿四 | 北方小年（廿三）/ 南方小年（廿四），两天都提 |
| 腊月最后一天 | 除夕（廿九或三十，以当月是否月大为准，来源会写「除夕」） |

月历页上的道教/地方诞辰（如「黄老诞」）可作为「民俗纪念日」另列，不要升格成全民法定节。

#### 4.2 公历固定节日（用 Y-M-D 匹配）

至少覆盖：1/1 元旦，3/8 妇女节，3/12 植树节，5/1 劳动节，5/4 青年节，6/1 儿童节，7/1 建党节，8/1 建军节，9/3 抗战胜利纪念日，9/10 教师节，10/1 国庆节。  
9/8 国际扫盲日、11/8 记者节等国际日，有权威源再写，没有就不要编。

清明、冬至既是节气也当节日报。

#### 4.3 法定节假日 / 调休（放假安排）

**主源（已验证）**：

```
https://timor.tech/api/holiday/info/YYYY-MM-DD
https://timor.tech/api/holiday/year/YYYY
```

当日接口示例：`{"code":0,"type":{"type":0,"name":"周二","week":2},"holiday":null}`  
`holiday == null` 且 `type.type == 0` → 工作日；`type.type == 1` 周末；有 `holiday` 对象则是假日或调休（看 `holiday: true/false` 和 `name`）。

从 year 接口算「距离下一个法定假日还有几天」（只数 `holiday: true` 的第一天，如 2026-09-25 中秋）。

放假安排以国务院办公厅通知为准。timor 只是镜像，**涉及具体调休时应用 `web_search("国务院办公厅 Y年部分节假日安排")` 交叉**；搜到通知但打不开 gov.cn（常见 403）就引用转载标题+日期，并写「以国办通知原文为准」。

#### 4.4 当日其它纪念日（可选）

`web_search({ query: "Y年M月D日 是什么日子 节日", count: 5 })` 或百度日历「节日百科」。只收录能指回来源的，国际日/行业日放「纪念日」不要和春节中秋并列。

### 5. 黄历宜忌（可选，用户没问可省略）

`fetch_url("https://www.iamwawa.cn/huangli.html")` 默认是「今天」。指定日期则搜 `Y年M月D日 黄历` 或打开 `https://wannianli.tianqi.com/Y/M/D/`。

宜忌是民俗择吉，**必须标注「民俗参考，非科学依据」**。不同黄历宜忌经常打架（已实测 2026-09-08 蛙蛙「祭祀,出行,扫舍,馀事勿取 / 诸事不宜」，天气网万年历却列了一长串宜、忌为空），打架时并列两源，不要假装只有一个答案。

```markdown
## 📅 {公历YYYY年M月D日} · {星期X}

**农历 {干支年}（{生肖}年）{农历月日}**
干支：{年柱} {月柱} {日柱}（缺则省略月柱日柱）
星座：{星座}

### 🌾 节气
- **当日**：{是「白露」/ 不是节气当日}
- **当前节气**：{名称}（{公历日期}{时刻，有则写}）· 已过 N 天
- **下一节气**：{名称}（{公历日期}）· 还有 N 天

### 🎉 节日
- **传统节日**：{无 / 名称}
- **公历节日 / 纪念日**：{无 / 名称列表}
- **法定放假**：{工作日 / 周末 / 假日名称，是否调休}

### 🔜 临近
- 距 {下一传统或法定节日} 还有 N 天（{日期}）

### 📜 黄历宜忌（仅用户问起时）
- 宜：…
- 忌：…
- 说明：民俗参考；来源不一致时已并列。

---
数据日期：{YYYY-MM-DD}
数据来源：
- 农历：{链接}
- 节气：{链接}

```

临近节日优先报：最近的传统大节（春节/元宵/清明/端午/七夕/中秋/重阳）或法定假日，取更近的一个，其次再提教师节等。

### 7. 失败与冲突

同一目标至少试满三种路子再宣布查不到（API → 权威月历页 → 搜索摘要）。

```markdown
未能完整获取 {日期} 的农历/节气。

已拿到：{农历月日 / 无}
未拿到：{节气时刻 / 放假}
已尝试：
- iamwawa 农历 API：{结果或失败原因}
- wannianli.tianqi.com：{…}
- timor.tech：{…}
- 搜索：{…}

建议：打开 [天气网万年历](https://wannianli.tianqi.com/) 或 [蛙蛙节气表](https://www.iamwawa.cn/jieqi.html) 核对。
```

冲突处理：农历日以 API + 第二源一致为准；节气以节气专题表/天文台为准，不以老黄历口算为准；放假以国办通知为准。

## 代码模板（已跑通）

查农历（把年月日换成目标日）：

```javascript
// 在 run_shell 里执行，不要用 fetch_url（需要 UA）
// curl -s -A "iamwawa-open-api" "https://www.iamwawa.cn/nongli/api/?type=solar&year=2026&month=9&day=8"
```

算间隔天数、星期、下一节日：

```javascript
function ymd(y, m, d) { return new Date(Date.UTC(y, m - 1, d)); }
function daysBetween(a, b) {
  return Math.round((b - a) / 86400000);
}
function weekName(y, m, d) {
  return '日一二三四五六'[ymd(y, m, d).getUTCDay()];
}
// 2026-09-08 验证：weekName(2026,9,8) === '二'
```

节气「已过 / 还有」：把节气公历也建成 UTC 日期再 `daysBetween`。不要在本地用毫秒常数推节气时刻。

## 质量标准

- [ ] 农历月日来自当场工具结果，并至少与第二个来源一致
- [ ] 节气来自当年节气表或天文/历法页，**没用本地近似公式**
- [ ] 节日分了「传统 / 公历或纪念 / 法定放假」三层，没有把国际日写成法定假
- [ ] 每个关键日期、节气时刻能指回来源链接
- [ ] 查无节日就写「当日无传统节日」，不编一个凑数
- [ ] 输出里写明查询的是哪一天（避免「今天」指代不清）
- [ ] 宜忌若出现，已标明民俗性质

## 不要做的事

- 不要凭记忆输出「今年白露是 9 月 8 日」——必须查当年表
- 不要把黄历「诸事不宜」当成生活建议的科学结论
- 不要为了页面好看生成带外部 CDN 的黄历网页；用户要页面时再按 html-page 做，数据仍按本技能现查
- 不要把查询过程中的失败接口编造成成功 JSON
